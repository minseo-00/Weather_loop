# Weather_loop

## 프로젝트 소개
Weather_loop는 날씨와 음악, 감성 일기장을 결합한 웹 서비스입니다. 사용자는 실시간 날씨 정보에 따라 추천 음악을 듣고, 감정과 음악을 기록하는 일기장을 작성할 수 있습니다. Spotify API와 OpenWeatherMap API를 활용하여, 사용자 경험을 극대화하였습니다.

## 주요 기능
- **날씨 기반 음악 추천**: 사용자의 위치와 실시간 날씨 정보를 바탕으로 음악을 추천합니다.
- **Spotify 연동**: OAuth 2.0 인증을 통해 Spotify 계정으로 로그인하고, Web Playback SDK로 음악을 재생할 수 있습니다.
- **감성 일기장(CRUD)**: 음악, 날씨, 감정, 메모를 함께 기록하고, 일기를 생성/조회/수정/삭제할 수 있습니다.
- **즐겨찾기(북마크)**: 좋아하는 음악을 즐겨찾기로 관리할 수 있습니다.
- **회원가입/로그인**: bcrypt로 비밀번호를 암호화하여 안전하게 회원 정보를 관리합니다.

## 기술 스택
- **프론트엔드**: React (Next.js)
- **백엔드**: Node.js (Express)
- **DB**: MySQL (mysql2 드라이버 직접 사용)
- **인증/보안**: OAuth 2.0, bcrypt
- **API**: Spotify, OpenWeatherMap

## 개발 및 실행 방법
1. 환경 변수(.env) 설정 후, 각 디렉토리에서 `npm install` 및 `npm run dev`로 실행할 수 있습니다.
2. 개발 중 ngrok을 사용해 프론트엔드 서버를 외부에 공개하고, 백엔드는 로컬에서 프록시로 연결하는 구조입니다.

## 폴더 구조
- `/frontend` : 프론트엔드(Next.js) 소스 코드
- `/backend` : 백엔드(Express) 소스 코드
